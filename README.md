# ATM Simulator

A modern and responsive ATM Simulator developed using HTML, CSS, and JavaScript. This project replicates basic ATM functionalities, allowing users to securely log in with a PIN, check their balance, deposit and withdraw funds, and view transaction history.

## Features

- Secure PIN Authentication
- Real-Time Balance Updates
- Deposit and Withdraw Money
- Transaction History with Date & Time
- Local Storage Data Persistence
- Responsive User Interface
- Modern Banking Dashboard Design
- Logout Functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

## Purpose

This project was created to strengthen front-end development skills by implementing DOM manipulation, event handling, data persistence, and responsive design principles in a real-world banking simulation.
